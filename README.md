# 福彩体彩助手（安卓平板版）

适用于 9–14 寸安卓平板，大字体、高对比，方便老年人使用。横屏、竖屏自动切换。

## 功能

1. **最新开奖**：福彩3D、排列三、排列五
   - 同时查询 **新浪彩票** 和 **网易彩票**，哪家先出号码就先显示，标注"⏳ 待核对"
   - 两家都出且号码一致，显示"✅ 两家核对一致"
   - 两家号码不一致：不显示号码，继续重新获取
   - 获取不到：显示"暂无数据"，**绝不显示编造或旧的号码**
   - 每晚 21:12–22:30 每 10 秒自动刷新，其他时间每 1 分钟刷新
2. **开奖直播**：只打开福彩、体彩官方直播页面
   - 顶部"⬅ 返回"按钮 + "福彩直播 | 体彩直播"胶囊切换
   - 画面右下角超大"全屏"按钮
3. **历史数据**：近 3 年，来源新浪彩票，保存在平板上，今年的数据每次打开自动同步

## 下载安装 APK

**第一次安装**：打开本仓库右侧的 **Releases**，下载最新版里的 `caipiao-helper.apk`，传到平板上安装（不需要登录 GitHub）。

**以后更新**：直接在平板上操作——
- 打开 App 时会自动检查新版本，有新版本会弹出"发现新版本"，点"立即更新"
- 也可以在首页底部点"检查更新"
- 第一次更新需要在弹出的设置页里打开"允许安装应用"

每次修改代码后，GitHub 会自动打包并发布一个新版本（版本号自动加 1）。

## 修改直播地址

官方直播页面地址在 `app/src/main/java/com/niefeng/caipiao/LiveScreen.kt` 顶部的 `LiveConfig` 里。

## 说明

- 开奖数据来自新浪彩票、网易彩票网页，仅供参考，兑奖请以官方公告为准。
- 本 App 使用测试签名，仅供个人自用。
